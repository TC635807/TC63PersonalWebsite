# 调研简报（所有 Agent 必读）

- 调研主题：为"记录工作与作品"的个人主页收集**开源方案 / 结构 / 设计**，做成可当模板用的资料库。
- 数据采集日期：**2026-10-05**（所有"活跃度/star 数"等时效性数据都以此为准）
- 文档语言：中文，专有名词保留英文。

## 硬性规则

1. **只写自己负责的文件**（见各自任务描述）。绝对不要修改别人的文件；共享文件一律只读。
2. 每条结论必须带**来源 URL**。访问不到或没核实的，写"未核实"，**禁止编造** star 数、License、更新时间。
3. 写"官方 README 称…""演示站可见…"，不要写"我觉得/应该是"。
4. 原始抓取正文存到 `raw/<你的子目录>/`，文件名用 `域名-短标题.md`，文件第一行写原始 URL。
5. 宁可少而准，不要多而虚。每个文件末尾附"未解决/待核实"小节。

## 搜索与抓取工具现状（2026-10-05 实测）

| 工具 | 状态 | 用途 |
|---|---|---|
| `platform_search({platform:'github', query})` | ✅ 好用 | 找仓库（首选） |
| `advanced_search({engine:'exa'/'tavily'/'firecrawl'})` | ✅ 可用 | 找文章/清单/教程 |
| `multi_search` | ⚠️ 时好时坏 | 需要多源交叉时用 |
| `bing` | ❌ 英文查询返回词典垃圾 | 别用 |
| `ddg` / `searxng` | ❌ 当前不可用 | 别用 |
| `mcp__better-crawler__fetch_url` / `fetch_urls` | ✅ | 抓正文，支持 JS/反爬站；一次 ≤ 8 条 |
| `bash` + `curl` | ✅ | 检查演示站是否存活（只做 HEAD/GET 状态码） |
| `api.github.com` | ⚠️ 未认证 60 次/小时 | **仅 T5 可用**，其他人禁止调用 |
