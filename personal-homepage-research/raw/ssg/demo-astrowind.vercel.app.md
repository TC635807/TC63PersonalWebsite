TL;DR
For the people who scroll past the features and ask “how do I run it?”. This is how.
$ npm create astro@latest -- --template arthelokyo/astrowind
Answer the prompts, run npm run dev, open localhost:4321. The demo site is now yours to edit. The only requirement is a current Node.js.
