Nuxt Content
Nuxt Content reads the
content/
directory in your project, parses
.md
,
.yml
,
.csv
or
.json
files and creates a powerful data layer for your application. Bonus, use Vue components in Markdown with the
MDC syntax
.
📖 Read the documentation
✨ Intro video
✍️ Nuxt Studio
Features
Nuxt 3
support
Work in serverless and edge environments (Cloudflare Workers, etc.)
Render Vue components in Markdown with the
MDC syntax
Fully typed collections and queries
Navigation generation
Blazing fast hot module replacement in development
Code highlighting with
Shiki
Powerful query builder on top of SQLite database
... and more
