Quick Start
Add the repository into your Hugo Project repository as a submodule,
git submodule add https://github.com/luizdepra/hugo-coder.git themes/hugo-coder
.
Configure your
hugo.toml
. You can either use
this minimal configuration
as a base, or look for a complete explanation about all configurations
here
. The
hugo.toml
inside the
exampleSite
is also a good reference.
Build your site with
hugo server
and see the result at
http://localhost:1313/
.
