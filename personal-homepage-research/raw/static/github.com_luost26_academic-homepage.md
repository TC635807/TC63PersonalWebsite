Getting Started
First, click the "Use this template" button to create a new repository. The name of the repository should be
<your-github-username>.github.io
(click
here
to learn more about naming a GitHub Pages repository).
Running Locally (Debug & Preview)
Follow the
step 1
and
step 2
of the instruction
here
to install prerequisites and jekyll.
Clone your forked repository to your local machine.
Run the following command in the root directory of the repository:
bundle
exec
jekyll serve
Browse to the displayed URL to see the website.
Deploying to GitHub Pages
Go to the repository settings and enable GitHub Pages. Detailed instructions can be found
here
.
Navigate to your created website, and follow the instructions displayed on the homepage (if any) to finalize the setup.
