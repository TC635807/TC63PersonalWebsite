# 文档目录规划（v5：领域 + 单元）

> 本文件已并入 [文档撰写指南.md](./文档撰写指南.md)，内容以指南为准，此处仅留作历史。

> 本文档只是规划，**不是站点内容**（`docs/_plan/` 以 `_` 开头，构建期忽略）。
>
> **v5 口径**：领域 = 一个可独立成篇的**技术领域/工具**（能撑起多个子主题）；单元 = 它下面的**具体子主题**。
> v4 里那些"工程细节"（CRC16、DWT、ImuTempControl、裁判系统、功率控制、Message_Bus、vis-network…）**全部降级为单元**。
>
> 依据：5 个项目的源码遍历（两块固件板、KnowledgeDiver 前后端、better-crawler、mjx-go1-getup 全树、本站）+ 两个个人知识库。

## 合并对照（v4 → v5 的降级）

| v4 曾是领域 | v5 归属 |
| --- | --- |
| CRC8·CRC16 | → `04 串口通信与协议` 的单元 |

| DBUS 遥控 / 裁判系统 | → `04 串口通信与协议` 的单元 |
