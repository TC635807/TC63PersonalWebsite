## 0. 上一版为什么不合格（逐条避免）

用户反馈：上一版 `docs/36-VLM 机械臂抓取/` 把「本项目做了什么、实测多少、修过什么」当成了主体。
那是提交日志，不是技术文档。正确的主体是**工程设计的思路、原因、原理、为什么这样做**。

| 上一版的做法 | 这一版的要求 |
| --- | --- |
| 逐函数走读、贴大段源码、列"本机最近一次运行 44 用例"这类输出 | 讲机制与设计：为什么需要它、原理是什么、有哪些取舍 |
| 用"实测数字/验收记录/已知缺陷"充当章节 | 数字只用来支撑设计判断（阈值为什么是这个量级、量级差多少） |
| 项目实现是主角，概念是配角 | 概念是主角，项目实现是**例证**（一段最多一处具体名字，细节进末尾路径表） |
| 缺少语料固定的四件套：常见判断偏差、小结（核心概念+设计权衡）、练习、附路径 | 每篇必写，位置与形态照范文 |

判断标准很简单：把文中的项目名和类名全删掉，这篇文章**仍然能教会读者这件事**；范文就是这个标准。

## 2. 每篇的骨架（照范文来，不要自创）

1. **frontmatter**：`title` / `summary` / `tags` / `updated: 2026-10-15`。
2. **开场 1–2 段**：读者会遇到的真实问题（不是"本章讲…"），然后一句 roadmap：
   "下面先…，再…，最后…"。
3. **主体若干节**，每节回答一个设计问题：是什么 → 为什么需要 → 原理（公式/算法）→ 怎么选（取舍）
   → 代价与边界。分类与判据一律用表格；流程、状态、时序用 Mermaid。
4. **`## 常见判断偏差`**：表 `# | 判断偏差 | 表现 | 依据`，4–6 行。**每篇必写**。
5. **`## 小结`**：`### 核心概念`（4–6 条 bullet）+ `### 设计权衡`（表 `权衡点 | 常见选择 | 收益与代价`）。
6. **`## 练习`**：`### 基础题` 4 题（能动手核对的）+ `### 挑战题` 4 题（设计类：设计判据、
   检查清单、处置流程）。
7. **`## 附：本页引用的路径`**：表 `路径 | 用途`，列本项目里对应的文件/目录。

每篇 150–400 行，Mermaid ≥ 2 张，代码块必须标语言。

## 3. 语气与边界

- 主语是机制、概念、判据、读者会遇到的问题；不出现"我/本机/本次运行/最近一次"。
- **不写**运行日志、验收记录、bug 修复史、提交内容、调试过程、性能跑分。
- 数字出现时要有设计含义：阈值怎么定、量级差多少、为什么不能再小/再大。
- 项目实现是例证：一段最多一处具体类名/函数名/常量名；集中信息放"附：本页引用的路径"。
- 示意数据要标注「示意（不是本仓库原文）」；真实片段才写真实来源。
- 加粗 `**` ≤ 2（目标 0，范文是 0）；破折号 `——` ≤ 8；`不是…而是` = 0；禁用词正文 0；
  不写 `文件:行号`；不用第二人称"你"；不用 emoji/感叹号。
- 代码只贴能说明设计取舍的短片段（3–15 行），不整段搬运。

## 5. 事实素材（只作例证，不要当结构）

**机械臂本体**：UR5e（Menagerie）+ Robotiq 2F85，`MjSpec.attach` 挂法兰（prefix `g_`）；
编译 `nq=nv=14`、`nu=7`、`neq=3`；TCP site `g_pinch`；6 关节；`SIM_DT=0.002`（500 Hz）；
限位只有 elbow ±π，其余 ±2π；HOME 位形 `[-π/2,-π/2,π/2,-π/2,-π/2,0]`；指间距 ratio=1→93 mm、0→8.4 mm。

**运动学（`control/kinematics.py`）**：私有 `MjData` 做计算、只读复制 `env.data.qpos`；
`mj_kinematics + mj_comPos`（不跑 `mj_forward`，因为 IK 内循环开销）；雅可比 `(6,nv)=[jacp; jacr]`；
四元数 wxyz；MuJoCo 3.12 无 `site_xquat`，由 `site_xmat` 转；DLS：`dq = Jᵀ(JJᵀ+λ²I)⁻¹e + (I−J⁺J)k(q_c−q)`；
`λ` 自适应（下降减半、否则 ×4，上限 1e3）；`max_step=0.25` rad；`nullspace_gain=0.05`；
`n_restarts=6`、固定 RNG 种子；`tol=1e-3`（位置 m 与姿态 rad 同时）；给了 `q0` 只做一次热启动求解，
否则多次随机重启。实测往返 0.38 mm / 4.9e-4 rad。

**轨迹（`control/trajectory.py`）**：`min_jerk(s)=10s³−15s⁴+6s⁵`，两端速度与加速度为 0；
位置线性插值 + 同一 `s` 做 slerp；slerp 走最短弧，`d>0.9995` 退化为线性插值；
旋转向量小角用一阶近似；`duration` 有 1e-9 兜底、`sample(t)` 钳制。

**执行（`control/motion.py`）**：UR5e 位置执行器是 PD（前三个 kp=2000/kv=400，腕部 500/100，
`kv/kp` 统一 0.2 s），无重力补偿，HOME 静沉约 11 mm、任意关节角静差约 14 mm；
任务空间积分外环 `I ← clamp(I + g·dt·e)`，姿态修正左乘世界系（右乘会收敛到错固定点）；
速度前馈 `q = q_ik + (kv/kp)·J⁺[v;w]`，中段误差 28 mm → 12 mm；收尾伺服到 <1 mm；
错误码 `timeout/force_limit/ik_fail/unreachable/invalid_path`；中止先 halt（目标=当前角 + 空步）；
`force_limit_cap=200` N；接触段参考限速单步压入量 = v_max·dt，首触力随 v_max 下降（0.02 m/s 以上量级到百牛，
0.002 m/s 降到几牛），小步长段受"接触落在哪一控制步"影响，不是单调函数。

**规划（`planning/`）**：私有 `MjData` 做碰撞查询；`mj_forward` 后只统计"至少一个 geom 属于机器人"的接触；
父子 body 默认不生成接触；`is_state_valid` = 限位内且无碰撞；RRT-Connect 双向树，
`step_size=0.15`、`max_iters=4000`、`goal_bias=0.1`、边离散 0.02 rad（2..64 段）、每次 plan 按 seed 重新播种；
快路径起点直连；`shortcut` 随机两点直连、端点不变；`densify` 每段 ≤0.05 rad；
位姿规划多 IK 种子，不信任 `ik` 的 ok 标志、用 fk 复核位置 <5 mm（给了姿态才查 0.05 rad）；
后处理后再逐段复核。

**导纳（`control/admittance.py`、`core/types.py`）**：`M·ẍ + D·ẋ + K(x−x_ref) = −f_ext`，
x 为"位置3+旋转向量3"；半隐式欧拉；稳定条件 `dt·√(K/M) < 2`（推荐 ≤0.5）；
单步限幅平动 0.05 m、转动 0.15 rad，限幅后用 `delta/dt` 回算速度抗饱和；
`axes=0` 的轴纯位置跟随；`axes=1` 但 `m≤0` 退化为跟随并警告；
档位 stiff（k=5000/d=200/m=5/axes=0）、soft（k=300/30、d=30/6、m=2/0.2）、z_only（k=200/d=25/m=1.5）；
缩放 `k×f、d×√f、m 不变`；专用档 `PLACE(k=120,d=20,flim=20)`、`GRASP(k=200,d=25,flim=15)`、`PLACE_TOUCH(flim=6)`；
力符号严格按 `−f_ext`；sim 返回"作用在 EE 上"的力，取负后 EE 沿 +f 让位。

**VLM / Agent（`agent/`）**：慢环 0.5~2 Hz 事件触发，快环 500 Hz；
每步 `get_state + render` → 多模态 messages → `decide` → 校验 → 执行 → 观察回灌；
结束条件：stop/ask_user、同一 skill+error_code 连续失败 2 次、不可重试错误码第 2 次、步数上限；
不可重试码 `home_blocked/stuck/object_disturbed/scene_reset`；
场景 JSON 不含真值位姿（no-oracle）；图像 data URI（JPEG q85）、顺序固定；
VLMClient 只用标准库、`tools + tool_choice=auto`、先解析 `tool_calls` 再扫 content；
重试 4 次、退避 0.6/1.5/3.0/5.0 s、空回复翻倍 max_tokens；可重试 HTTP 408/425/429/500/502/503/504；
MockVLM 是无 key 时同路径的确定性决策器；工具 14 个（10 个技能 + 4 个控制面）；
参数白名单过滤未知字段、校验顺序白名单→类型/范围→场景一致性；14 个技能含 pick/place/push/home 等。

**子目标与复核（`agent/taskplan.py`、`skills/`、`sim/perception.py`）**：任务拆成有序子目标
（place_in_container / place_on_top / place_at / pick / free）；每个子目标开新 epoch，最多 3 次尝试；
判定顺序：容器内 → check_inside；叠放 → check_stacked；pick → 技能证据优先、缺失则 top 前后 check_gone；
其余 → VLM 复核且 confidence ≥0.6；异常一律 done=False，绝不谎报；
信息隔离：不读真值位姿，喂复核的 metrics 走白名单；
抓取验证：主判据是 top 前后"面积掉到 1/3 以下"，腕部视角是近似恒真的假阳性，只作反闸与兜底；
技能层：自由段刚性、接触段柔顺，抓取方向由 TCP 局部 +z 定义，闭合量按物体宽度反算，放置是 guarded move。
