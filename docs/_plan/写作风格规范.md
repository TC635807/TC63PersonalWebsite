# 文档写作规范（去 AI 腔）

> 本文件已并入 [文档撰写指南.md](./文档撰写指南.md)，内容以指南为准，此处仅留作历史。

> 适用对象：`docs/<领域>/<单元>/*.md` 的全部正文。写新单元或改旧单元都按这份来。
> 这份规范只约束**行文**，不约束技术内容：事实、数字、代码、表格、Mermaid 一律不动。

## 1. 目标

读起来像工程师写给同事的内部技术笔记：陈述为主、信息密度高、不表演、不抒情、不反复强调"这很重要"。
判断标准很简单——**把任何一句话单独摘出来，不应该出现"只有 AI 会这么写"的痕迹。**

## 2. 禁用句式

| 句式 | 例 | 改法 |
| --- | --- | --- |
| 不是……而是…… | "不是背配置，而是能回答……" | 直接写正面结论，或拆成两句："要能回答……。背配置没用。" |
| 并非……而是…… | 同上 | 同上 |
| 与其说……不如说…… | —— | 删掉评价，直陈事实 |
| 不是 X，是 Y | "不是运气好，而是设计取向" | 写"这是设计取向" |
| 设问开头 | "为什么中断版要返回值？" | 改陈述句："中断版需要返回值，因为……" |
| 元叙述 | "本章最需要照代码说话的一节"、"摊开看"、"把视野拉远" | 删掉，直接进入内容 |
| 命令式口头禅 | "记住这个数"、"值得逐条记住" | 删掉"记住"，把结论写出来 |
| 评价填充 | "非常值得优先怀疑的方向"、"值得肯定的地方" | 写"优先怀疑的方向"/"可取的做法是" |

## 3. 禁用词表（正文中不出现）

比喻与情绪词：`刺眼` `尖锐` `地雷` `手滑` `翻车` `体检` `尸体` `标本` `解剖` `裸奔` `裸` `一把梭` `稳如` `血腥` `致命` `杀手` `惊艳` `漂亮` `硬核` `狠`

替换建议：

| 原词 | 改用 |
| --- | --- |
| 陷阱 / 坑 | 易错点、问题、风险 |
| 体检 | 检查、排查 |
| 账 / 堆账 | 核算、预算、占用 |
| 标木 / 标本 | 例子、样本 |
| 裸奔 / 裸 | 无保护、直接访问 |
| 翻车 | 失败、出错 |
| 地雷 | 隐患 |
| 手滑 | 笔误、写错 |
| 致命 | 严重 |

（`陷阱` 允许出现在小节标题里，如"常见陷阱与调试"，正文中不用。）

其他要压掉的词：`一句话` `说白了` `换句话说` `其实` `本质上` `恰恰` `真正` `摊开` `值得` `记住` `本章` `本篇`。
说明：`其实`/`真正`/`恰恰` 不是绝对禁词，但每篇最多各留 1 处，且必须承载信息；通篇当语气词用就删。

## 4. 加粗规则（这是本次最需要改的）

现状是几乎每个断言都加粗，读起来全是重点，等于没有重点。

- **允许**：代码标识符、配置项名、文件名、函数名、寄存器名；术语**首次**出现时；表格表头里的关键字段。
- **禁止**：整句加粗、行首加粗引导句（`**注意最后三项**` 这类）、评价性加粗（`**极其关键**` `**代价**` `**本工程的情况**`）。
- 需要强调时，改用句子结构（把结论放句首或句尾），不要用加粗。
- 目标：每篇 `**` 出现次数比现在**下降 60% 以上**。

## 5. 标点与人称

- 破折号 `——` 每篇不超过 8 处；能用逗号、冒号、句号的地方就别用破折号。
- 少用第二人称"你"。确需对读者说话时用"需要……""应当……""注意……"。
- 感叹号、省略号、emoji：正文不用。

## 6. 鼓励的写法

- 陈述句为主，主语尽量是"本工程 / 该函数 / 这个值 / 两块板"。
- 一个句子一个信息点；不写排比，不写三连句。
- 结论先行，再给依据（源码行号、实测数字）。
- 对比用表格，流程与关系用 Mermaid，推导用公式。
- 保留"设计权衡"这类小结表，但表内文字同样按上面规则写。

## 7. 自检

改完在仓库根跑一遍，人工看数字：

```bash
for f in $(find docs/01-FreeRTOS -name '*.md' | sort); do
  printf "%-46s bold=%s dash=%s erShi=%s trap=%s
" "$(echo $f | sed 's#docs/01-FreeRTOS/##')" \
    "$(grep -o '\*\*' "$f" | wc -l)" "$(grep -o '——' "$f" | wc -l)" \
    "$(grep -oE '不是[^。；]{0,30}而是' "$f" | wc -l)" "$(grep -rhc '陷阱\|坑\|体检\|裸\|翻车' "$f")"
done
```

硬指标：`不是…而是` = 0；加粗比改前降 ≥60%；破折号 ≤8/篇；禁用词正文 0 处；`本章`/`本篇` = 0。
