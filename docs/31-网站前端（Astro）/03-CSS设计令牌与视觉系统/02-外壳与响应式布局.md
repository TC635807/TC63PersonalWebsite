# 外壳与响应式布局

把浏览器窗口从宽拖到窄，会看到一件事发生：左侧那条写法的竖直导航在某个宽度突然变成顶部横条，同时正文的左边距消失。这个切换点是 900 像素，由两条互补的媒体查询完成（`src/styles/global.css` 的外壳段）。

除这个翻转之外，外壳还有一套统一的几何：居中容器、区块间距、区块头、主视觉两栏栅格与切角面板。它们都用变量或 `clamp()` 表达，随窗口连续变化，而不是在每个断点写一套尺寸。

这套外壳由全部子页共用：导航、间距、按钮与区块头的几何只在这里定义一次，调整站点版式不必逐页修改。若每个页面各自写尺寸，同一个间距会在多份样式里重复出现，改一处就容易漏一处。

窗口在两个断点之间时，页面保持最近一次形态，不会出现中间态。这也意味着窄屏与宽屏的观感差距只在跨过断点的那一刻补上。

## 重置与基础排版

文件开头做了最低限度的重置（`global.css` 的基础段）：

```css
*, *::before, *::after { box-sizing: border-box; }
html { scroll-behavior: smooth; }
body {
  margin: 0;
  background: var(--paper);
  color: var(--ak-text-primary);
  font-family: var(--ak-font-sans);
  font-size: 16px;
  line-height: 1.75;
  -webkit-font-smoothing: antialiased;
}
img, svg { display: block; max-width: 100%; }
a { color: var(--violet-700); text-decoration: none; }
h2 { font-size: clamp(1.5rem, 2.6vw, 2.25rem); }
```

`box-sizing: border-box` 让宽高把内边距与边框算进去，之后所有宽度计算都少一层加减。正文排版规定在 `body` 上：字号十六像素、行高 1.75、字体走正文栈，并开启字体抗锯齿。二级标题字号用 `clamp(最小值, 首选值, 最大值)`：浏览器取中间那个基于视口宽度的 `vw` 值，超出范围时夹到两端——所以标题随窗口连续变化，不会在某个断点突然跳变。

行内代码有浅底与细边框，微标签统一成大写宽字距的样式，还有一条紫色短线作为层级标记。这套基础规则被后面的所有区块复用。

## 居中容器与竖栏

内容容器限制最大宽度并水平居中，左右内边距用 `clamp()` 连续变化；竖栏固定定位在左侧：

```css
.shell { max-width: var(--shell-max); margin-inline: auto; padding-inline: clamp(20px, 3.4vw, 56px); }
@media (min-width: 900px) { body { padding-left: var(--rail-w); } }

.rail {
  position: fixed; inset: 0 auto 0 0; width: var(--rail-w); z-index: 60;
  background: var(--paper); border-right: var(--ak-line-hairline) solid var(--line);
  display: flex; flex-direction: column; align-items: center; padding-block: 22px;
}
```

`position: fixed` 让竖栏脱离文档流、固定在视口左侧，所以 `body` 必须补上等于它宽度的左内边距，否则正文会被压在下面。`inset: 0 auto 0 0` 是四边偏移的简写（上 0、右 auto、下 0、左 0）。

导航文字用竖排书写模式，当前页高亮靠属性选择器（`global.css` 的竖栏规则）：

```css
.rail__nav a {
  writing-mode: vertical-rl; text-orientation: mixed;
  font-family: var(--ak-font-command); text-transform: uppercase; letter-spacing: var(--ak-type-wide);
  color: var(--ink-3); padding-block: 6px; border-top: 2px solid transparent;
}
.rail__nav a[aria-current='page'] { color: var(--violet-700); border-top-color: var(--violet-600); }
```

`writing-mode: vertical-rl` 把文字排成自上而下的竖排；`border-top` 平时透明，只有 `aria-current='page'` 的项才染紫——高亮由语义属性决定，样式里不需要额外的类名。

```mermaid
flowchart TD
    A[窗口宽度] --> B{"不小于 900px?"}
    B -->|是| C[body 加竖栏左内边距]
    C --> D[竖栏固定左侧、纵向导航]
    B -->|否| E[竖栏变顶部吸附横条]
    E --> F[导航横向、高亮线移到底部]
```

## 窄屏下的翻转

窄屏媒体查询把竖栏从固定改成吸附、从纵向改成横向，导航文字恢复横排，高亮线从顶边移到底边：

```css
@media (max-width: 899px) {
  .rail { position: sticky; inset: auto; width: auto; height: 60px; flex-direction: row; justify-content: space-between; padding: 0 clamp(16px, 4vw, 24px); border-right: 0; border-bottom: var(--ak-line-hairline) solid var(--line); }
  .rail__mark { width: 34px; height: 34px; }
  .rail__nav { flex-direction: row; gap: 22px; margin: 0; }
  .rail__nav a { writing-mode: horizontal-tb; border-top: 0; border-bottom: 2px solid transparent; }
  .rail__nav a[aria-current='page'] { border-top-color: transparent; border-bottom-color: var(--violet-600); }
}
```

媒体查询就是"只在满足条件时生效的一段样式"，这里用 `max-width` 与上面宽屏的 `min-width` 互补；`position: sticky` 让它随页面滚动吸附在顶部。同一套标记在两种形态下都能用，因为布局差异全部写在媒体查询里，结构不变。这也是为什么导航组件不需要判断屏幕宽度——它只负责渲染语义正确的链接。

## 区块头与主视觉栅格

内容区块用统一的上下留白类，分常规与紧凑两档，间距同样用 `clamp()` 随窗口变化；区块头是"序号 + 标题 + 一条伸展的细线 + 右侧更多链接"的横向结构：

```css
.sec { padding-block: clamp(48px, 7vw, 104px); }
.sec--tight { padding-block: clamp(36px, 4.5vw, 64px); }
.sec-head { display: flex; align-items: flex-end; gap: var(--ak-space-4); margin-bottom: var(--ak-space-5); }
.sec-head__rule { flex: 1; height: var(--ak-line-hairline); background: var(--line); margin-bottom: .55rem; }
```

细线的 `flex: 1` 让它在弹性布局里吃掉标题与右侧链接之外的全部剩余空间，不需要写死宽度。主视觉区默认单列，窗口到一千像素以上变成两栏：

```css
.hero { display: grid; gap: clamp(28px, 4vw, 64px); align-items: center; padding-block: clamp(40px, 6vw, 92px); }
@media (min-width: 1000px) { .hero { grid-template-columns: 1.04fr .96fr; } }
.hero__name { margin: var(--ak-space-3) 0 var(--ak-space-2); font-size: clamp(2.6rem, 7vw, 5rem); letter-spacing: -.03em; }
```

比例是一点零四比零点九六——`fr` 是栅格的份数单位，接近均分但略有偏向，用来让文字栏稍宽一点。姓名用超大字号与负字距（负值让大字排得更紧），定位语用命令字栈并着强调色，下面一排指标用等宽字体显示数值、用大写宽字距显示标签。

## 切角几何与按钮

面板与按钮的"切角"效果用裁剪路径实现：从左下到右上切掉一个角，其余三个角保持直角：

```css
/* 切角面板 —— 只切一个角（非对称几何） */
.cut { background: var(--paper-2); border: var(--ak-line-hairline) solid var(--line); clip-path: polygon(0 0, calc(100% - var(--ak-cut-lg)) 0, 100% var(--ak-cut-lg), 100% 100%, 0 100%); }
.cut--md { clip-path: polygon(0 0, calc(100% - var(--ak-cut-md)) 0, 100% var(--ak-cut-md), 100% 100%, 0 100%); }

.btn {
  display: inline-flex; align-items: center; gap: var(--ak-space-2);
  min-height: var(--ak-density-control-height); padding: 0 var(--ak-space-5);
  font-family: var(--ak-font-command); text-transform: uppercase; letter-spacing: var(--ak-type-wide);
  color: var(--ink); background: var(--paper); border: var(--ak-line-hairline) solid var(--line-2);
  clip-path: polygon(0 0, calc(100% - var(--ak-cut-sm)) 0, 100% var(--ak-cut-sm), 100% 100%, 0 100%);
  transition: color var(--ak-motion-fast) var(--ak-ease-standard), border-color var(--ak-motion-fast) var(--ak-ease-standard), background var(--ak-motion-fast) var(--ak-ease-standard);
}
```

`clip-path: polygon(...)` 用一组坐标点裁剪元素形状，这里右上角那两点被削掉，形成切角；`calc(100% - var(--ak-cut-lg))` 让坐标能引用变量。切角尺寸来自上游变量，分大中小三档，面板用大档、按钮用小档，形成一致的斜轴。

按钮是行内弹性盒子，`transition` 只在颜色与边框上过渡，悬停时文字与边框变成强调色；主按钮用深紫底白字。标签与徽章是更小的同类元素，左侧加一条短竖线或描边区分状态——徽章里"进行中"与"私人"用不同的描边与文字色表达，颜色承担信号作用。

## 断点一览

全站外壳的断点很少，每个负责一件事：

| 断点 | 作用 |
| --- | --- |
| 620px 以下 | 获奖列表与紧凑面板压成纵向 |
| 760px 以上 | 两栏与三栏栅格启用 |
| 900px 以上 | 竖栏固定左侧、正文留左边距；项目行分两栏 |
| 1000px 以上 | 主视觉分两栏；详情页分元信息与正文两栏 |

断点之外的尺寸变化交给连续函数，所以窗口拖动时只有形态切换是突变的。

## 首屏图像与装饰层

主视觉的图形容器固定四比三比例并裁掉溢出，流体背景的载体绝对定位铺满（`global.css` 的主视觉段）：

```css
.visual { position: relative; aspect-ratio: 4 / 3; overflow: hidden; }
.fluid-wrap { position: absolute; inset: 0; }
.fluid-wrap canvas { width: 100%; height: 100%; mix-blend-mode: multiply; }
.visual__hud { position: absolute; inset: 0; pointer-events: none; }
```

`aspect-ratio` 让容器按比例自动算高，`overflow: hidden` 把超出比例的部分裁掉。画布用 `mix-blend-mode: multiply`（相乘混合）与白底相乘，紫色因此落成浅紫而不是实色块。装饰层 `pointer-events: none` 表示它不接收鼠标事件，下面的画布仍然能被指针碰到。

图形内部的括号、刻度、圆弧与十字分别用不同变量描边，构成工业感的辅助线。项目示意图里的文字样式也在这份样式表里统一规定，图形内文字与页面使用同一套字体与色板。

## 焦点与动效降级

焦点样式只对键盘可见焦点生效，轮廓宽度、颜色与偏移都来自上游变量：

```css
:focus-visible { outline: var(--ak-focus-width) solid var(--ak-focus-color); outline-offset: var(--ak-focus-offset); }
```

`:focus-visible` 只在浏览器判断"用户是键盘操作"时才匹配，鼠标点击不会留下轮廓；变量又都来自上游，换主题时焦点样式跟着变。

动效方面有两条保护。一条媒体查询在用户要求减少动效时把过渡与动画整个关掉：

```css
@media (prefers-reduced-motion: reduce) {
  html { scroll-behavior: auto; }
  * { transition: none !important; animation: none !important; }
}
```

入场动效那组类只在脚本执行后才隐藏元素（上一单元已说明）。样式表里还有若干栅格类的断点，把两栏与三栏布局在窄屏压成单列。

```mermaid
stateDiagram-v2
    [*] --> 宽屏
    宽屏 --> 窄屏: 窗口小于 900px
    窄屏 --> 宽屏: 窗口回到 900px 以上
    note right of 宽屏
        竖栏固定左侧, 导航竖排
    end note
    note right of 窄屏
        竖栏吸附顶部, 导航横排
    end note
```

## 易错点

| 位置 | 问题 | 建议 |
| --- | --- | --- |
| `global.css` | 竖栏宽度同时用于固定宽度与正文左内边距，只改一处会错位 | 改动时两处一起核对 |
| `global.css` | 断点分散在多个媒体查询里，新增布局容易漏掉窄屏 | 新组件先在小窗口下看一遍 |
| `global.css` | 裁剪路径切掉的角在不同尺寸下观感不同 | 用统一的三档变量 |
| `global.css` | 高亮依赖语义属性，缺属性时看不出当前位置 | 导航项都带上属性 |
| `global.css` | 减少动效只压时长，仍有布局位移的动画 | 位移类动效一并处理 |
| `global.css` | 正文行高按中文调的，插入大段英文时略松 | 需要时局部收紧 |

## 小结

### 核心概念

* 外壳几何用变量与连续函数表达，断点只处理形态翻转。
* 居中容器限制最大宽度，宽屏下给正文留出竖栏的左边距。
* 竖栏在 900 像素以下从固定侧栏翻成顶部吸附横条。
* 导航高亮通过语义属性选择器实现，结构不随形态变化。
* 切角由裁剪路径实现，尺寸分三档，与按钮共享同一条斜轴。
* 焦点样式与动效降级都接到上游变量和用户偏好上。
* 主视觉容器固定比例并裁掉溢出，装饰层不接收指针事件。

### 设计权衡

| 选择 | 收益 | 代价 |
| --- | --- | --- |
| 间距用连续函数 | 不同窗口下过渡自然 | 无法精确预期某个宽度的数值 |
| 单一断点翻转竖栏 | 移动端与桌面差异清晰 | 中间尺寸下侧栏已消失 |
| 切角代替圆角 | 风格统一、辨识度高 | 裁剪会裁掉溢出内容 |
| 高亮用语义属性 | 无需额外类名 | 忘记属性就没有高亮 |
| 动效降级压时长 | 尊重用户偏好 | 复杂动画仍需单独处理 |
| 画布用相乘混合 | 颜色自然融进白底 | 深色底上需要另调 |
| 形态由断点切换 | 实现简单、行为可预期 | 断点两侧存在一次视觉跳变 |

## 练习

### 基础题

1. 竖栏在两种形态下的差异有哪些，结构为什么不用改。
2. 居中容器与正文左边距分别由什么变量决定。
3. 切角是怎么实现的，三档尺寸分别用在哪里。

### 挑战题

4. 增加一个 1200 像素以上的宽屏布局，列出需要调整的栅格与间距，并说明如何避免影响现有断点。
5. 给竖栏加一个折叠成图标条的状态，设计状态存储与样式切换方式，并说明无脚本时如何降级。
