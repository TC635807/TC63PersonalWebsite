# 加窗与实时流式频谱

第一篇的推导假定分析序列正好是整数个周期，这在实验台上可以构造，在机器人上几乎不会出现。传感器数据是连续流，取其中一段做 FFT 等于把无限长信号乘以一个矩形窗，截断处的不连续会在频谱上产生泄漏：原本集中在单根谱线的能量扩散到邻近频段，弱信号被强信号的旁瓣淹没。

加窗是抑制泄漏的标准手段，代价是主瓣变宽、频率分辨能力下降。实时处理还有第二个问题：数据持续流入，单次 FFT 只能得到一段时间的频谱，如何处理相邻窗之间的关系决定了频谱更新率与时间分辨率。

## 截断为什么产生泄漏

对无限长信号取 $N$ 点等于乘以矩形窗。时域相乘对应频域卷积，信号的真实频谱与矩形窗的频谱卷积之后，原本位于单点的能量按窗的频谱形状铺开。矩形窗的频谱是 sinc 函数，主瓣窄但旁瓣衰减慢，第一旁瓣只比主瓣低约 13 dB，意味着一个强分量的旁瓣可以掩盖邻近频率上低 13 dB 以上之外的弱分量（`03_sensor_algorithms/fft/README.md`）。

泄漏的严重程度取决于信号频率与谱线位置的相对关系。频率正好落在谱线中心时泄漏最小，落在两根谱线之间时最大。工程上无法保证这一点，因此加窗是默认动作，只有做瞬态冲击分析或采样已与信号同步时才用矩形窗。

```mermaid
flowchart LR
  A["无限长信号"] --> B["乘矩形窗 取 N 点"]
  B --> C["频域卷积 sinc 函数"]
  C --> D["能量扩散到邻近谱线"]
  D --> E["加窗压低旁瓣"]
  E --> F["主瓣变宽 分辨率下降"]
```

## 五种窗函数的主瓣与旁瓣

素材给出的窗函数对比如下（`README.md`）：

| 窗类型 | 主瓣宽度 | 旁瓣衰减 | 典型用途 |
| --- | --- | --- | --- |
| 矩形窗 | $2\pi/N$ | 约 13 dB | 瞬态信号、同步采样 |
| Hann | $4\pi/N$ | 约 32 dB | 通用振动分析 |
| Hamming | $4\pi/N$ | 约 43 dB | 语音与窄带信号 |
| Blackman | $6\pi/N$ | 约 58 dB | 高动态范围 |
| Flat Top | $8\pi/N$ | 约 90 dB | 幅值精度优先 |

主瓣宽度决定分辨能力，旁瓣衰减决定弱信号能否被看见，两者反向。Hann 窗的主瓣是矩形窗的两倍、旁瓣低 19 dB，是振动分析的通用选择。Flat Top 的旁瓣低到 90 dB，代价是主瓣宽四倍，只适合已经知道频率位置、只需要精确幅值的场合。Blackman 与 Hamming 处在中间，按动态范围需求选取。

主瓣宽度用 bin 数表示更直观：$4\pi/N$ 对应两个 bin，$8\pi/N$ 对应四个 bin。因此用 Hann 窗时，相隔两个 bin 以内的两个峰无法区分；要提高区分能力必须增大 $N$ 而不是换窗。

## 幅值恢复与代码实现

加窗会让幅值变小，需要按窗的相干增益补偿，示意如下：

```python
# 示意：加 Hann 窗并恢复幅值
w = np.hanning(N)                      # 窗函数
X = np.fft.rfft(x_windowed := x * w)   # rfft：实数输入只算一半谱线
coherent_gain = w.sum() / N            # 相干增益：窗的平均值
amplitude = 2 * np.abs(X) / (N * coherent_gain)   # 幅值恢复（单边谱乘 2）
```

"泄漏"指截断造成的不连续在频域表现为能量扩散：一段有限长信号相当于把无限长信号乘了矩形窗，而矩形窗的频谱有很高的旁瓣，能量会从真实谱线漏到邻近频段。加窗让截断处的幅值平滑落到零、压低旁瓣，代价是主瓣变宽、频率分辨率下降。`rfft`利用实信号频谱的共轭对称只算一半，省一半计算量，代价是恢复幅值时单边谱要乘 2（直流与奈奎斯特点除外）。

Hann 窗的解析形式是（`README.md`）：

$$
w[n] = 0.5 - 0.5 \cos\left(\frac{2\pi n}{N-1}\right), \qquad n = 0, 1, \dots, N-1
$$

逐点与应用窗的代码只有三行（`README.md`）：

$$
x_w[n] = x[n] \cdot w[n]
$$

加窗之后谱线幅值被窗本身的增益压低，需要乘以恢复系数

$$
K = \frac{N}{\sum_{n=0}^{N-1} w[n]}
$$

Hann 窗的求和约为 $N/2$，因此恢复系数约等于 2（`README.md`）。

这里有一个常见混淆：恢复系数只对落在谱线中心的分量精确，落在两根谱线之间的分量幅度还要乘一个与偏移量相关的因子，最大偏差约 1.4 dB（Hann 窗的扇贝损失）。若应用要求精确幅值，要么让频率落在谱线中心，要么用 Flat Top 窗，要么对峰值做抛物线插值。

## 重叠窗口与跳长

实时处理把窗沿时间轴滑动，每次前进的长度叫跳长（hop length）。素材给出的方案是 50% 重叠，即每 $N/2$ 个新样本执行一次 FFT（`README.md`）。重叠的作用有两个：提高频谱更新率，以及减小单个样本落在窗边缘带来的信息损失。

| 重叠比例 | 跳长 | 更新率 | 计算量倍数 |
| --- | --- | --- | --- |
| 无重叠 | $N$ | $f_s/N$ | 1 |
| 50% | $N/2$ | $2f_s/N$ | 2 |
| 75% | $N/4$ | $4f_s/N$ | 4 |

重叠比例提高时频谱更新更快，但单位时间内的 FFT 次数按比例增加。以 $f_s = 1$ kHz、$N = 256$ 为例，无重叠时每秒 3.9 次 FFT，50% 重叠时 7.8 次，$N$ 点 FFT 的耗时乘以次数就是算力需求。机器人振动监测通常取 50%，兼顾时间分辨率与计算量。

```mermaid
flowchart LR
  A["采集 N/2 个新样本"] --> B["旧后半段搬到前半段"]
  B --> C["新样本写入后半段"]
  C --> D["执行 FFT"]
  D --> E["幅度谱分析"]
  E --> A
```

## 缓冲区的管理方式

素材给出的流式实现是单缓冲区滑动（`README.md`）：

$$
\text{buffer} \leftarrow \left[ \text{buffer}[N/2 \dots N-1], \; \text{new\_samples} \right]
$$

每采集 $N/2$ 个新样本，用 memmove 把旧的后半段搬到前半段，再把新数据填到后半段，然后执行 FFT。这段拷贝每跳长一次，搬运 $N/2$ 个浮点数。

素材文字里把这套结构称为 ping-pong buffer，但从代码看它是单缓冲区的滑动窗口，两者有差别：标准的乒乓结构用两块缓冲区与指针交换，新数据写入一块的同时对另一块做 FFT，省掉搬运并且不需要在中断与主循环之间共享同一块内存（`README.md`）。数据量小的时候两种做法差别不大，$N = 1024$、跳长 512 时每次搬运 2 KB，在中低主频 MCU 上已经是可观的固定开销。

若 FFT 在主循环执行、采集在中断执行，单缓冲方案还需要处理并发：中断写后半段而主循环读整段时可能出现撕裂。常见做法是加一个就绪标志或双缓冲，乒乓结构本身就是对这种并发问题的标准答案。

## 分辨率与有效窗长

频率分辨率由采样率与点数决定（`README.md`）：

$$
\Delta f = \frac{f_s}{N} = \frac{1}{T_{\text{window}}}
$$

其中 $T_{\text{window}} = N/f_s$ 是窗的时间长度。这个式子说明分辨率等于有效数据时长的倒数，与窗函数选择无关；加窗只是把主瓣加宽到两到四倍，实际可分辨间隔相应放大。

| $f_s$ | $N = 64$ | $N = 128$ | $N = 256$ | $N = 512$ |
| --- | --- | --- | --- | --- |
| 1 kHz | 15.6 Hz | 7.81 Hz | 3.91 Hz | 1.95 Hz |
| 10 kHz | 156 Hz | 78.1 Hz | 39.1 Hz | 19.5 Hz |

选择 $N$ 时先按需要分辨的最小频率间隔定有效窗长，再按最高关注频率定采样率，最后由 $\Delta f$ 反推需要的 $N$。顺序颠倒会出现两种返工：先定 $N$ 再看采样率，可能发现奈奎斯特频率不够；先定采样率再看 $N$，可能发现窗太长、更新太慢。

## 小结

### 核心概念

- 截断等于乘矩形窗，频域卷积使其频谱铺开，旁瓣造成弱信号被强信号掩盖。
- 主瓣宽度决定分辨能力，旁瓣衰减决定动态范围，两者反向；Hann 窗是振动分析的通用选择。
- 加窗后乘恢复系数 $K = N / \sum w[n]$ 得到真实幅值，Hann 窗约为 2；谱线之间的分量还有扇贝损失。
- 实时处理用重叠窗口，50% 重叠使更新率翻倍、计算量翻倍，是振动监测的常用折中。
- 分辨率等于有效窗长的倒数，$\Delta f = f_s/N = 1/T_{\text{window}}$，与窗函数无关。

### 设计权衡

| 选择 | 带来的能力 | 付出的代价 |
| --- | --- | --- |
| 用 Hann 窗 | 旁瓣低 19 dB | 主瓣宽一倍 |
| 用 Flat Top 窗 | 幅值精度高 | 主瓣宽四倍，无法分辨近峰 |
| 提高重叠比例 | 频谱更新快 | 计算量按比例上升 |
| 用乒乓缓冲 | 免搬运、并发安全 | 内存翻倍、指针管理复杂 |
| 增大 $N$ | 分辨率与动态范围提高 | 计算量与延迟上升 |

## 练习

### 基础题

1. 说明矩形窗的旁瓣衰减数值以及它带来的实际后果。
2. 计算 $f_s = 4$ kHz、$N = 256$ 时的频率分辨率与窗长，并说明用 Hann 窗后可分辨的最小间隔。
3. 写出加窗后的幅值恢复步骤，说明 Hann 窗的恢复系数为什么约等于 2。

### 挑战题

4. 比较无重叠与 50% 重叠在 $f_s = 2$ kHz、$N = 512$ 下的每秒 FFT 次数与耗时，给出算力占用估算。
5. 设计一个双缓冲流式 FFT 方案，说明写入与计算的分工、就绪标志的置位时机以及撕裂的避免方法。
6. 分析扇贝损失对幅值测量的影响，给出用抛物线插值补偿峰值的步骤与残余误差。
